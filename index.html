Como o score é calculado

Cada estabelecimento recebe uma nota de 0 a 100. O alvo principal é o negócio visível no mapa, com demanda comprovada e sem vitrine digital.

  • 01
    Sem site

    Quem não tem website próprio (ou só redes sociais) ganha o maior bônus. São os leads mais quentes para oferta de presença digital.

  • 02
    Estrelas

    A média de 1 a 5 indica qualidade percebida. Notas altas com pouco digital são o melhor sinal de oportunidade.

  • 03
    Volume de avaliações

    Muitas reviews mostram movimento real. Usamos uma curva logarítmica para não distorcer quem tem milhares de notas.

  • 04
    Lugar

    Proximidade do ponto buscado (bairro, rua ou centro da cidade). Quanto mais perto do alvo, maior a pontuação.

  • 05
    Telefone

    Contato direto acelera o outreach. Leads com telefone público recebem um incremento extra.

Fonte de dados

Sem chave, o radar usa dados de demonstração e, se você escolher, o mapa aberto (OpenStreetMap). Com a chave do Google Places, a busca replica o Maps: estrelas, avaliações e se o estabelecimento tem site.

Como pegar a chave do Google
  1. Abra o Google Cloud Console e crie um projeto.
  2. Ative o faturamento (Billing). O Google exige cartão; há crédito grátis de teste.
  3. Em APIs e serviços → Biblioteca, ative Maps JavaScript API e Places API (a clássica, não só a “New”).
  4. Em Credenciais, clique em Criar credenciais → Chave de API e copie o valor (começa com AIza).
  5. Cole a chave aqui, marque Google Places e salve. A chave fica só neste navegador.

Restrinja a chave a essas duas APIs e ao seu domínio (ou localhost) para ninguém gastar o seu crédito.
